# PanSou v0.2.5

PanSou 0.2.5 makes stateful provider login and source configuration safer and easier to understand.

## Changes

- Add explicit `add`, `del`, and `list` actions for Weibo target users and QQPD channels.
- Explain QR scanning, mobile confirmation, expired-code recovery, and required post-login setup for
  Weibo and QQPD.
- Accept numeric IDs or full profile/channel URLs in the relevant Weibo and QQPD configuration
  commands.
- Add provider-specific login help and actionable success or credential-failure guidance for Gying
  and Panlian.
- Preserve authentication-specific exit codes for scripts while showing clearer credential errors.

## Upgrade notes

Weibo and QQPD configuration now uses explicit actions. Update existing command invocations to use
`add`:

```bash
# Before
pansou provider configure weibo --profile main --user 1234567890
pansou provider configure qqpd --profile main --channel example

# PanSou 0.2.5
pansou provider configure weibo add --profile main --user 1234567890
pansou provider configure qqpd add --profile main --channel example
```

Use the corresponding `del` and `list` actions to remove or inspect configured targets. Existing
saved profiles, cookies, target users, and channels remain compatible; no state migration is
required. After the release is published, install it with:

```bash
pansou update --version v0.2.5
```
