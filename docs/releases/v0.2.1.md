# PanSou v0.2.1

## Changes

- Use English throughout CLI help and describe every command and option.
- Suggest `pansou channel import --builtin` when built-in candidates are missing from the saved channel list.
- Enable newly imported channels by default for built-in catalogs, local files, and HTTP(S) URLs. Pass `--disable` to import new entries as disabled.
- Add `pansou channel enable --all` and `pansou channel disable --all`.

## Upgrade notes

Run `pansou update` from v0.2.0, or reinstall using the installation script.

Import now enables new entries, unlike v0.2.0. Existing channels retain their saved status, including disabled channels. Use `--disable` in scripts that need the previous import behavior. No configuration migration is required.

Importing or enabling channels beyond the 128-enabled-channel limit rejects the entire operation without partially changing the list. `--all` cannot be combined with channel names.

```bash
pansou channel import --builtin
pansou channel import channels.txt --disable
pansou channel enable --all
pansou channel disable --all
```
