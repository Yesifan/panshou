# PanSou v0.2.0

## 新功能

- 新增 `channel` 命令：添加、删除、启用、禁用频道，支持内置清单、本地文件和 URL 导入。
- 频道独立保存到 `channels.toml`，同时启用上限为 128；导入的新频道默认禁用。
- 搜索默认流式输出，来源完成即返回结果；保留 8 并发。
- 新增 `--all-timeout`，默认搜索阶段总时限 600 秒；`--timeout` 仍表示每来源超时。
- 修复 Telegram inline keyboard 链接解析及正文关键词命中回退。
- 新增 `update`、`update --check` 和指定版本升级，校验安装包并检查配置兼容性。
- Help 展示当前配置的搜索等待时间估算，并提示优先使用短关键词。

## 升级须知

- v0.1.0 没有 `update` 命令。首次升级请重新运行仓库安装脚本，或从本次 Release
  下载对应平台安装包、校验 `SHA256SUMS` 后替换原二进制；之后可使用 `pansou update`。
- `config.toml` 中的 `search.channels` 不再生效，也不会自动迁移。
  请使用 `pansou channel add` 或 `pansou channel import` 重新建立频道配置；导入后按需启用。
- 搜索移除 JSON 输出，请改用 `--format jsonl` 或默认表格输出；`check` 的 JSON 输出不变。
- 总时限到达时保留已输出结果，并以退出码 124 结束；脚本应处理部分结果。

完整命令和配置说明见 [使用指南](../usage.md)。
