# PanSou v0.2.2

## Changes

- Validate search results by default and emit only links confirmed as `ok`.
- Add `pansou search --no-check` to skip validation and show every discovered link.
- Remove the former `pansou search --check` and `--valid-only` options.

## Upgrade notes

Search scripts now perform network validation unless `--no-check` is supplied. Links reported as
`bad`, `locked`, `uncertain`, or `unsupported` are omitted from the default output.

Replace explicit `--check` or `--valid-only` usage with the default command:

```bash
pansou search "query"
```

Use `--no-check` when callers need the previous unchecked result stream:

```bash
pansou search "query" --no-check
```

No configuration migration is required.
