# PanSou v0.2.4

## Changes

- Preserve Magnet and ED2K links during searches with default link checking enabled.
- Exclude Magnet and ED2K links from cloud-drive validation instead of reporting them as invalid
  link formats.
- Keep the existing `ok`-only filter for cloud-drive types supported by link checking.

## Upgrade notes

Magnet and ED2K search results no longer require `--no-check` to remain in the final output. They
are returned without a `check` field because cloud-drive validation does not apply to these link
types.

No configuration migration is required.
