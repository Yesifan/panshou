# PanSou v0.2.3

## Changes

- Show provider login QR codes directly in compatible terminals using a dense Unicode renderer,
  while retaining a temporary PNG fallback when terminal rendering is unavailable.
- Replace incremental search output with dynamic search and link-check progress bars on stderr,
  followed by one stable, merged result on stdout.
- Add `pansou search --no-progress`; progress is also hidden automatically when stderr is not an
  interactive terminal.
- Restore `pansou search --format json` as one final summary document containing checked links,
  source status, timing, and validation totals.
- Remove JSONL output from both `search` and `check`; both commands now support `table` and `json`.
- Preserve completed, checked results in the final summary when search is interrupted with Ctrl-C.

## Upgrade notes

Scripts consuming search JSONL events or check JSONL rows must switch to the single JSON document:

```bash
pansou search "query" --format json
pansou check URL --format json
```

Interactive search now waits for source collection and link validation before writing final results
to stdout. Use `--no-progress` to suppress terminal progress while retaining ordinary diagnostics,
or `--quiet` to reduce both progress and non-essential logs.

No configuration migration is required.
